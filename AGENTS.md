# AGENTS.md

## 1. Visao geral

Este e o portfolio pessoal de Claudio Henrique.

O objetivo do site e apresentar posicionamento profissional, stack, cases selecionados, experiencia e canais de contato. O conteudo deve ser coerente com LinkedIn e GitHub, priorizando uma narrativa de desenvolvedor fullstack ativo, com experiencia real em produto, sistemas web, Angular, Laravel, Next.js, Docker e uso pragmatico de IA no fluxo de desenvolvimento.

## 2. Stack

Stack real detectada no projeto:

- Next.js
- React
- TypeScript
- Tailwind CSS
- next-themes
- react-feather
- @headlessui/react

## 3. Comandos uteis

Comandos disponiveis no `package.json`:

```bash
npm run dev
npm run build
npm run start
npm run lint
npm run lint:fix
npm run type-check
npm run format
```

## 4. Diretrizes de implementacao

- Priorizar legibilidade e simplicidade.
- Evitar overengineering em um site de conteudo pequeno.
- Manter componentes pequenos quando isso melhorar clareza e manutencao.
- Evitar adicionar bibliotecas sem necessidade.
- Preservar acessibilidade, semantica HTML e navegacao por teclado.
- Manter responsividade em mobile, tablet e desktop.
- Evitar textos inflados, genericos ou exageradamente marketeiros.
- Usar linguagem profissional, clara e objetiva.
- Nao expor dados sensiveis de empresas, clientes, usuarios ou operacoes internas.
- Tratar cases profissionais privados como cases descritivos, sem links, codigo, telas ou dados sensiveis.
- Manter o site alinhado a narrativa: fullstack, product engineering, sistemas web reais, Angular/Laravel/Next.js/Docker e AI workflows.

## 5. Direcao visual

- Estetica clean, premium e profissional.
- Base neutra com grafite, tons claros/off-white e bom contraste.
- Accent em terracota/cobre, alinhado a identidade visual atual do LinkedIn.
- Evitar visual infantil, excesso de emojis, excesso de badges e animacoes chamativas.
- Evitar aparencia de template generico.
- Preferir secoes bem espacadas, textos objetivos e hierarquia visual clara.

## 6. Conteudo e tom

O tom deve ser:

- profissional;
- direto;
- sobrio;
- tecnico quando necessario;
- sem exagero promocional;
- sem excesso de informalidade.

Nao afirmar graduacao concluida. Se formacao for mencionada, usar "Ciencia da Computacao - graduacao incompleta" ou omitir.

## 7. Validacao

Antes de finalizar alteracoes relevantes, rodar:

```bash
npm run lint
npm run type-check
npm run build
```

Se algum comando nao funcionar por problema pre-existente ou configuracao do projeto, registrar:

- comando executado;
- erro observado;
- causa provavel;
- sugestao de correcao.
